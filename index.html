Features

干活之前，先把计划摊开

AwesEvo 不玩黑箱：AI 要做哪几步、正在做哪一步、做完了没有，都摆在界面上。权限、工具、活动范围，全都可以按你的规矩关小或放大。

📋

可见的执行计划

每次任务先生成带勾选框的计划，执行一步勾一步；思考过程可折叠展开，它想了什么、为什么这么做，都看得到。

🎚️

权限三档

只读只能看不能动；确认每步先问你；自动放手让它跑。危险命令会被单独拦下来确认，删文件永远先进回收站。

🔌

多服务商 · 多模型

OpenAI / Anthropic 兼容端点自由添加，一键拉取端点下的模型列表实时切换；装了 Ollama 会自动探测接进来。

🧭

活动范围围栏

首次启动二选一：只在专用工作区里读写，或全权接管用户目录。无论哪种，系统目录和密钥目录永久拒绝访问。

🔐

密钥加密存储

API Key 用 AES-256-GCM 加密，种子与本机硬件绑定，配置文件里只剩密文；界面上也只显示后四位。

📸

快照与后台

一键保存工作区快照，随时回滚；设置页带「后台」面板，运行状态和日志不用翻文件夹就能看。

Get Started

三步，从下载到开聊

01

下载单文件 exe

不用装 Node、不用配环境——运行时已经打包在 AwesEvo.exe 里，89.5 MB 一个文件。

02

双击启动

程序会自动解压到 %LOCALAPPDATA%\AwesEvo 并打开界面，先选好 AI 的活动范围（工作区模式最稳妥）。

03

填 Key 开聊

没 Key 也能先用内置的免费体验通道聊起来（纯对话）；在「设置 → 模型与 API」填上自己的 Key，就能解锁全部工具能力。

Safety

能干活，也得守规矩

让 AI 在自己电脑上跑命令，安全不是附加题。AwesEvo 的防护是后加的一整套系统，每一条都写进了代码里：

  • ✓来源校验 —— 本地接口只接受本机页面调用，浏览器里随便一个网页别想指挥它
  • ✓路径围栏 —— 工具只能碰活动范围内的文件，越界直接拒绝
  • ✓删除进回收站 —— 没有「彻底删除」，手滑了还能捞回来
  • ✓危险命令拦截 —— 命中高危模式必须人工确认，并有重复调用检测和最大步数兜底

FAQ

常见问题

收费吗？要注册吗？

都不要。AwesEvo 免费开源，没有账号体系，下载下来就是你的。

我的数据会上传吗？

不会。会话、配置、工作区文件都存在本机；它只会连接你自己填写的模型 API 端点。

没有 API Key 能用吗？

能。内置免费体验通道可以直接对话（有频率限制且不能调用工具）；填自己的 Key 后解锁完整能力。
