client = OpenAI(
    api_key="sk-xkl-...",
    base_url="https://zz.299326.xyz/v1",

resp = client.chat.completions.create(
    model="gemini-3.8-flash",
    messages=[{"role": "user", "content": "用一句话解释黑洞"}],
)

print(resp.choices[0].message.content)

FAQ

你可能想问的

需要自己去 Google 申请 API Key 吗？
不需要。注册后在控制台生成一把 sk- 开头的令牌，上游的对接、轮换和限流都由中转站处理。
免费层真的不要钱？会不会偷偷扣费？
免费层额度本身不收费，我们只做转发，不加价。额度耗尽时会返回明确的错误码，不会自动切换到付费通道，也不会静默扣费。
支持流式输出吗？
支持。请求里加 "stream": true，返回标准 SSE，格式和 OpenAI 完全一致，前端可以直接用现成的解析器。
图片和 PDF 怎么传？
图片用 OpenAI 的 image_url 结构，base64 或外链都行；PDF 建议直接走文件字段，或者先抽成文本再发。
被限流了怎么办？
免费层有速率上限，触发时返回 429 并带 retry-after。按这个值退避重试就行，别硬刷——硬刷只会让冷却时间变长。
和直接用官方 Gemini API 有什么区别？
协议统一成 OpenAI 格式、令牌由我们统一管理、多模型之间可以只改一个字符串就切换。功能上没有删减，多模态、流式、长上下文都保留。

还是没找到答案？
